# 能力分配表

全游戏一共 23 个音乐小游戏和任务：第一关 10 个，第三关 13 个（其中“你自己”不考分）。**每一个考的能力都不一样。** 以后加新题之前，先查这张表，确认要考的能力还没有出现过。

## 第一关：每年一个音乐小游戏（`js/minis.js`）

| 年 | 场景 | 考什么能力 | 代码 |
|---|---|---|---|
| 1 | Livehouse 暖场 | 跟着节拍按准（下落音符，方向键） | `rhythm` |
| 2 | 帮吉他手调弦 | 把音调到和标准一样高 | `tune` |
| 3 | 录音棚试音 | 听音：单音（含变化音）、音程、和弦，参考音是标准音 la | `ear` |
| 4 | 节拍器坏了 | 没有节拍器，自己稳住速度（只算每两下的间隔，不受耳机延迟影响） | `tempo` |
| 5 | A&R | 分辨真人还是 AI 弹的 | `ai` |
| 6 | 乐团排练 | 在整个乐团里听出是哪件乐器在独奏（选项是音色相近的乐器，只放一次） | `solo` |
| 7 | 主舞台救场 | 数小节，在乐句结尾敲过门（没有提示，有假过门，有三拍子） | `fill` |
| 8 | 慢歌录制 | 编曲：把鼓、贝斯、和弦一层层拼对 | `arrange` |
| 9 | 综艺半决赛 | 旋律记忆：一个八度八个音（简谱 1 到高音 1），只能靠耳朵，越来越长 | `simon` |
| 10 | 综艺总决赛 | 终极对决：你 vs AI 歌手。不考节奏音高，考写词的真情实感、读现场、临场表达，观众投票 | `finale` |

## 第三关：每个身份一个任务（`js/levels.js` 的 `TASKS`）

| 身份 | 考什么能力 | 代码 |
|---|---|---|
| 广告配乐人 | 音乐的情绪（悲伤） | `mood` |
| 婚礼音乐顾问 | 几拍子（华尔兹三拍子） | `waltz` |
| 人声制作人 | 空间感：混响让声音听起来在哪里（贴耳的小房间、大教堂、浴室） | `space` |
| AI 训练师 | 和弦在不在调内 | `chords` |
| 纪录片作曲 | 音色质感（温暖柔和） | `timbre` |
| 你自己 | 不考分：用第二关的 8 个音编成快、慢、悲伤三版，选中的成为第四关开场音乐 | `self` |
| 健身教练 | 听呼吸声 | `breath` |
| 咖啡馆店主 | 音乐会不会盖住说话声 | `cafe` |
| 乐器修复师 | 听杂音 | `buzz` |
| 康复治疗师 | 音乐速度和走路的步子对得上 | `gait` |
| 音乐老师 | 找出弹错的那个音（错在左手和弦里，只差半音） | `wrongnote` |
| 音乐节摄影师 | 抓住高潮的第一拍 | `drop` |
| 酒吧驻唱 | 从跑调的哼唱里认出原曲 | `hum` |
