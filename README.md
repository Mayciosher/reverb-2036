# 十年回响 · Reverb 2036

一个关于“十年后的音乐人如何过”的音乐游戏，课程选题 1（设计一款音乐游戏）× 选题 8（十年后的音乐人一天怎么过）。

在线试玩：https://mayciosher.github.io/reverb-2036/ （仓库开启 GitHub Pages 后可用，手机和电脑都能玩）

仓库名 reverb 是“混响”，也就是录音棚里的回响；2036 是故事里的“十年后”。

## 四个关卡

| 关卡 | 玩法 | 背景音乐 |
| --- | --- | --- |
| 1 饿死之前 | 左右滑卡片做选择，撑过 2027 到 2036 年。数值到 0 或 100 会遇到“人生岔路”，共 19 种结局。中途有演出、听音、人机辨听三种音乐关卡 | Lo-fi 爵士，每过一年加一条音轨，数值越危险越紧张 |
| 2 音乐命运签 | 抽三张音乐塔罗牌，或随手弹 8 个音，算出十年后的你 | 神秘竖琴（弗里吉亚属调式） |
| 3 制作人的一天 | 2036 年的一天，7 个甲方提 7 个要求，用耳朵从 AI 给的 3 个版本里挑 | 合成器浪潮，越晚越快 |
| 4 十年回响 | 回看前三关的选择，写 4 个音，由管弦乐奏成你的“十年回响” | 管弦乐，结局决定大调还是小调 |

所有音乐都由浏览器 Web Audio 实时合成，没有使用任何现成歌曲。

## 文件分工

| 文件 | 内容 | 适合谁改 |
| --- | --- | --- |
| `index.html` | 页面结构、各屏幕的固定文字（首页、规则说明） | 文案 |
| `style.css` | 颜色、字体、布局 | 视觉 |
| `game.js` | 全部游戏逻辑和数据 | 见下表 |

`game.js` 里按注释分段，改文案时搜索这些标题即可：

| 搜索这个注释 | 里面是什么 |
| --- | --- |
| `曲风` | 四关背景音乐的和弦、节奏、音色 |
| `第一关数据` | 卡牌 `CARDS`、她模式卡牌 `HER`、音乐关卡入口 `MINIS`、人生岔路 `CRISIS`、结局 `ENDINGS` |
| `第一关：音乐关卡` | 演出、听音、人机辨听三个小游戏 |
| `第二关：音乐命运签` | 塔罗牌 `TAROT`、签文 `VERSE` |
| `第三关：制作人的一天` | 七个任务 `TASKS` |
| `第四关：十年回响` | 回望和终章 |

改卡牌最简单：复制 `CARDS` 里的一行，改 `who`（谁说的）、`say`（说了什么）、`L` / `R`（左右两个选项）。`e:{m:钱, f:名气, l:热爱, o:原创}` 是数值变化，正数加、负数减。新的说话人要在 `PEOPLE` 里加一行头像字和颜色。

## 协作流程（GitHub Desktop）

1. 每次开始改之前，先点 **Fetch origin / Pull origin**，拿到别人的最新版本。
2. 用 VS Code 等编辑器改文件，直接双击 `index.html` 就能在浏览器里试玩。
3. 回到 GitHub Desktop，左下角写一句改了什么，比如“新增第一关卡牌 3 张”，点 **Commit to main**。
4. 点 **Push origin** 上传。
5. 改之前在群里说一声“我在改 ××”。两个人同时改同一个文件的同一段，就会出现冲突。
